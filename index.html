Блок 1. Як створити заголовки різних рівнів?

В HTML для створення заголовків використовуються теги від <h1> (головний заголовок сторінки) до <h6> (найменший підзаголовок).

Блок 2. Як форматувати текст у HTML?

В HTML для форматування тексту використовуються різні теги, такі як:

  • <strong> - для жирного тексту
  • <em> - для курсивного тексту
  • <u> - для підкресленого тексту

Блок 3. Як створити гіперпосилання на зовнішній ресурс?

Відповідь: Гіперпосилання створюються за допомогою тега <a>. Обов'язковий атрибут href вказує URL-адресу, а атрибут target="_blank" відкриває посилання у новій вкладці.

HTML-код:

<a href="https://www.w3schools.com/html/default.asp" target="_blank">Документація W3Schools</a>

Результат у браузері:

Документація W3Schools

Блок 4. Як додати зображення на веб-сторінку?

Зображення додаються одинарним тегом <img>. Атрибут src визначає шлях до файлу (локального або URL), а alt містить альтернативний текст для доступності.

HTML-код:

<img src="https://en.wikipedia.org/wiki/File:HTML5-logo.svg" alt="Логотип HTML5" width="350">

Блок 5. Як створити маркований (невпорядкований) список?

Використовується контейнерний тег <ul> (unordered list), а кожен окремий пункт списку загортається в тег <li> (list item).

HTML-код:

<ul>
    <li>Мова розмітки HTML</li>
    <li>Таблиці стилів CSS</li>
    <li>Мова програмування JavaScript</li>
</ul>

Результат у браузері:

  • Мова розмітки HTML
  • Таблиці стилів CSS
  • Мова програмування JavaScript

Блок 6. Як створити нумерований (впорядкований) список?

Відповідь: Для нумерованого списку застосовується тег <ol> (ordered list), де кожен елемент так само розміщується всередині <li>.

HTML-код:

<ol>
    <li>Встановити VS Code</li>
    <li>Створити структуру файлів</li>
    <li>Відкрити проект у браузері</li>
</ol>

Результат у браузері:

  1. Встановити VS Code
  2. Створити структуру файлів
  3. Відкрити проект у браузері

Блок 7. Як створити список термінів та визначень?

Використовується тег <dl> (description list). Термін задається за допомогою <dt> (definition term), а його опис — через <dd> (definition description).

HTML-код:

<dl>
    <dt><strong>HTML</strong></dt>
    <dd>Мова гіпертекстової розмітки для створення структури сторінки.</dd>
    <dt><strong>CSS</strong></dt>
    <dd>Мова опису зовнішнього вигляду та стилів веб-документа.</dd>
</dl>

Результат у браузері:

Мова гіпертекстової розмітки для створення структури сторінки.
CSS
Мова опису зовнішнього вигляду та стилів веб-документа.

Блок 8. Як побудувати таблицю даних?

Відповідь: Таблиця створюється тегом <table>. Рядки формуються тегом <tr>, заголовні клітинки — <th>, а звичайні комірки з даними — <td>.

HTML-код:

<table>
    <tr>
        <th>Тег</th>
        <th>Призначення</th>
    </tr>
    <tr>
        <td>&lt;p&gt;</td>
        <td>Параграф (абзац)</td>
    </tr>
    <tr>
        <td>&lt;table&gt;</td>
        <td>Таблиця</td>
    </tr>
</table>

Результат у браузері:

Тег Призначення
<p> Параграф (абзац)
<table> Таблиця

Блок 9. Як вивести спеціальні символи (HTML Entities)?

Відповідь: Оскільки символи < і > зарезервовані для тегів, для них використовують HTML-сутності: &lt; для менше, &gt; для більше, &amp; для амперсанда, а також &copy; для знака копірайту.

HTML-код:

<p>Копірайт: &copy; 2026 | Стрілка: &rarr; | Тег: &lt;div&gt;</p>

Результат у браузері:

Копірайт: © 2026 | Стрілка: → | Тег: <div>

Блок 10. Як оформити блокову цитату?

Відповідь: Для оформлення відокремлених цитат із зовнішніх джерел використовується тег <blockquote>, а джерело можна вказати за допомогою атрибута cite або тега <cite>.

HTML-код:

<blockquote cite="https://uk.wikipedia.org">
    "Веб — це більше ніж просто технологія, це інструмент людської комунікації."
    <footer>— <cite>Тім Бернерс-Лі</cite></footer>
</blockquote>

Результат у браузері:

«Веб — це більше ніж просто технологія, це інструмент людської комунікації.»
